## FAQ

### What Windows versions are supported?

XCutors supports Windows 10 and Windows 11 (64-bit). Windows 7/8 may work but are not officially supported.

### My anticomponent flags the files as tool. Is it safe?

Anticomponent programs commonly flag script executors due to how they interact with game processes. We recommend adding an exclusion folder, but always download from this official GitHub repository only.

### Is using an executor against Roblox Terms of Service?

Yes, using third-party executors violates Roblox's Terms of Service and may result in account suspension or ban. Use at your own risk and consider using alternate accounts.

### How do I keep the executors updated?

Check the GitHub Releases page regularly for new versions. Each update includes compatibility fixes for the latest Roblox patches.

### The executor fails to attach or inject. What should I do?

Make sure Roblox is running, run the executor as Administrator, and ensure your anticomponent is not blocking the process. Restart both the executor and Roblox if the issue persists.

### Can I create my own Lua scripts?

Absolutely. XCutors supports custom Lua scripting. You can write your own scripts or find community scripts online and load them through the executor interface.

### Where can I get help or report bugs?

Open an Issue on this GitHub repository with a detailed description of your problem. Include your Windows version, executor used, and steps to reproduce the issue.

### Does this work on mobile or Mac?

No. XCutors is designed exclusively for Windows desktop. Roblox executors on other platforms require different tools.

### What is the universal loader (xcutorsLoader)?

The xcutorsLoader is a centralized management tool that lets you launch, configure, and switch between all included executors from a single interface.
